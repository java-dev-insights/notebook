# Frontend Development

A typical front-end development tech stack includes foundational languages like HTML (structure), CSS (styling), and JavaScript (interactivity), along with JavaScript frameworks/libraries such as React, Angular, or Vue.js for building dynamic user interfaces.  

Other components often found in a front-end stack are CSS preprocessors like Sass, TypeScript for large-scale projects, version control systems like Git, and build tools and package managers to automate tasks and manage dependencies.
